      ภาพนี้คือเฟรมแรกของวิดีโอชั้นวางที่จะใช้ตอนท้าย model ตัวนี้เจอทุกชิ้นโดยไม่ต้องรู้ชื่อ จึงใช้กับสินค้าอะไรก็ได้ และเร็วกว่าเพราะรันแค่ model เดียว

      1. ภาพเต็ม → detect()model ชั้นวางหาสินค้าทุกชิ้น

      3. ครอป → detect()model ชื่อสินค้าตั้งชื่อ
      4. รวมเป็นช่องชื่อเดียวกันที่ติดกัน = 1 ช่อง
      5. เฝ้า → เตือนdetect(ภาพ, {shelfOnly}) ทุก 1 วิ

      5 / 6 · ตัวอย่างการใช้งานจริง

      เฝ้าชั้นวางจากวิดีโอ แล้วเตือนเมื่อของหมด

      บันทึกหน้าจอเว็บนี้จริง (agent v0.3.2, WASM) กับวิดีโอทดสอบ 2 นาที เร่ง 3 เท่า · เตือนเมื่อว่าง 15 วินาที · กดหัวข้อเพื่อข้ามไปได้

        ตอนแรก agent ใช้ทั้ง 2 model หาช่องเองจากภาพชั้นเต็ม จากนั้นเฝ้าด้วย model ชั้นวางทุกวินาที ผลคือเตือนครบ 3 ช่องที่ของหมดจริง ไม่มีเตือนผิด แม้มีคนเดินผ่าน

        0.927mAP@0.5 model ชั้นวาง (SKU-110K)

        6 / 6 · สรุป

        ใช้งานได้จริงใน browser ทั้งคอมและมือถือ

        • Model ชื่อสินค้า: แม่นสูงกับ 110 ชนิดที่เทรน
        • Model ชั้นวาง: เจอสินค้าทุกชนิด ใช้เฝ้าช่องว่าง
        • Agent: รวมสอง model ตรวจความถูกต้องของไฟล์ และ pin เวอร์ชันกับเว็บ
        • ยังไม่ได้ทดสอบ: ชั้นวางและกล้องจริงในร้าน
        ลองตรวจจับลองเฝ้าชั้นวาง

        สรุปคือ 2 model ทำงานเสริมกัน: ตัวหนึ่งบอกชื่อ ตัวหนึ่งบอกว่ามีของไหม agent รวมให้ใช้ง่าย และเว็บเอาไปเตือนของหมดได้จริง

        เกี่ยวกับ

        เว็บนี้ตรวจจับสินค้าบนชั้นวาง 110 ชนิดด้วย YOLOv8n ที่เทรนบน dataset Sell Products แล้ว export เป็น ONNX ให้รันใน browser ด้วย onnxruntime-web (WebGPU หรือ WASM) ไม่มี server รูปที่เลือกหรือถ่ายจะถูกประมวลผลในเครื่องนี้เท่านั้น

        หน้า "เฝ้าชั้นวาง" ใช้อีก model หนึ่ง: YOLOv8n คลาสเดียว (product) ที่เทรนบนรูปชั้นวางของ SKU-110K โหมดเริ่มต้นตรวจภาพเต็มหนึ่งครั้งต่อ snapshot แล้วจับคู่กล่องกับช่องสินค้า; ช่องที่ยังไม่แน่ใจค่อยตรวจ crop ตามคิวยุติธรรมเท่าที่ทันในรอบนั้น (งบ ~0.9 วินาที) ช่องที่ยังไม่มีผลยืนยันหรือผลเก่าแล้วแสดงว่า "รอตรวจ" ไม่ถือว่าเป็นช่องว่าง ปุ่ม "หาช่องอัตโนมัติ" ใช้ทั้งสอง model กับภาพเต็มหนึ่งครั้ง (กล่องที่ model 110 คลาสไม่รู้จักจะถูก crop มาระบุชื่ออีกรอบ) แล้วรวมสินค้าชนิดเดียวกันที่วางติดกันในแถวเดียวกันเป็นหนึ่งช่อง (ไม่เกิน 6 ชิ้นต่อช่อง) จึงควรกดตอนชั้นเต็ม ถ้าช่องว่างนานเกินเวลาที่ตั้งจะแจ้งเตือนว่าของหมด ช่วงที่มีคนบังช่อง (ภาพเปลี่ยนมาก) จะหยุดนับเวลาและแสดงว่า "ถูกบัง"
